# Эмиль — веб- и Telegram-разработка

Портфолио: https://atlaceo.github.io
Связаться: https://t.me/atlamain

Статический сайт на HTML, CSS и JavaScript. Без сборки и зависимостей.

## Демонстрационные проекты

- `studio.html` — концепция сайта студии FORMA с выбором направления и формой записи.
- `miniapp.html` — браузерное демо интерфейса Mini App с выбором времени и списком записей.
- `bot.html` — интерактивная симуляция диалога Telegram-бота.

FORMA — вымышленная студия. Это самостоятельные демонстрационные проекты, не клиентские кейсы. Данные не отправляются и хранятся только до обновления страницы. Демо Mini App не подключено к Telegram SDK; демо бота не является серверным Telegram-ботом.

## Запуск

Открыть `index.html` в браузере. GitHub Pages публикует ветку `main` из корня репозитория. Файл `.nojekyll` отключает обработку Jekyll.

## Редактирование

Главная: `index.html`. Дизайн: `style.css`. Демо: `demo.css` и `demo.js`.
